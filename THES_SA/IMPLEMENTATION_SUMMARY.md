# THES_SA Implementation Summary (v2.0)

*Updated March 2026 - Revised per advisor feedback*

## What Changed (v1.0 -> v2.0)

| Area | v1.0 | v2.0 |
|------|------|------|
| Core Set | SMR, LEU, NNE | SMR, LEU, LTBR, NXE, NNE, LAC |
| Benchmark Set | XOM, CVX, NEE, DUK, SO, D | CCJ, CEG, BWXT |
| Frequency | Daily + Intraday (1h) | Daily only |
| Lookback | 6 months | 12 months |
| Features | MA(5,10,20), Bollinger, many | RSI, MA(10,50), MACD |
| Target | daily_change | 1d/5d forward log returns |
| Model | RF (planned) | LSTM (Baseline + Augmented) |
| Evaluation | Classification metrics | MAE, DA, Diebold-Mariano |
| New | - | Phase 0 audit, SHAP analysis |
